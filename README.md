工程表自動生成アプリ
ブラウザ上で動作する、建設業向けの工程表（ガントチャート）作成・管理ツールです。サーバー構築は不要で、HTMLファイルをブラウザで開くだけで利用できます。

🔹 主な機能
直感的な工程作成・編集

工種、工事内容、表示形式、日程（開始日・終了日）の入力。

日程や休日設定に基づく実働日数の自動計算。

ドラッグ不要のボタンによる工程の上下並び替え。

AI画像認識（手書き工程表の読み取り）

画像をアップロードするだけで、Google Gemini API（無料）が工程を自動解析して追記。

工種が未記載の場合でも、工事内容から適切な工種をAIが推測。入力候補として複数提案します（直接編集も可能）。

JSONデータからの直接取り込み

外部のAIツール（ChatGPT等）で作成した工程データ（JSON形式）をテキストエリアに貼り付け、一括で取り込み可能。

データの保存と管理

入力データはブラウザ（ローカルストレージ）に保存。宛先・工事名・担当者ごとに管理および絞り込み検索が可能です。

PDF出力・印刷対応

A4横サイズに最適化されたレイアウトで、そのまま印刷やPDFファイルとしての保存が可能です。

🔹 動作環境
推奨ブラウザ：Google Chrome, Microsoft Edge, Safari の最新版

PC、タブレット、スマートフォンに対応（レスポンシブデザイン）

🔹 使い方
起動

本ツールのHTMLファイルをブラウザで開きます。

AI画像認識機能の初回設定

「📷 手書き工程表から読み込む」メニュー内の「APIキーの設定」を開きます。

Google AI Studio にて無料のGemini APIキーを取得し、入力して「保存」を押します。（キーはブラウザ内にのみ安全に保存されます）

出力

画面下部の「PDF出力・印刷」ボタンを押すと、印刷プレビュー画面が立ち上がります。

🔹 注意事項
入力したデータやAPIキーは、お使いの端末（ブラウザのローカルストレージ）にのみ保存され、外部サーバーには送信されません（AI画像認識実行時のみ、画像をGoogleのAPIへ送信します）。

ブラウザのキャッシュや閲覧データを削除すると、保存した工程表データやAPIキーも消去されるためご注意ください。
